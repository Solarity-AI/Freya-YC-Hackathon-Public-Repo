Facet F1: who calls, who answers, and what may be said before identity is verified.

- bank.language: the call language as a 2-letter ISO 639-1 code (en, tr, de, ...): the language the brief says
  the calls are held in, else the language of its example conversations, else the brief's own language. All
  spoken lines of every facet are written in this language.
- bank.name: the bank's name as written. bank.assistant_self: how the agent names itself, using <bank> (e.g.
  "<bank>'s digital assistant" when the brief says the agent is the bank's digital assistant).
  bank.currency: symbol / word / position ("none" when the brief writes amounts without a currency).
- call_variables.declared: every call variable the brief lists, with a one-line generic meaning (never the example
  values). customer_key = the variable passed to every tool call; now = the variable with the current date-time.
- addressing.customer: how the customer is named in lines, only <v:...> placeholders (e.g. "<v:salutation> <v:surname>"
  when the brief says salutation plus surname). name_vars: the variables holding the customer's own name tokens
  (first and last name variables), used to recognise "this is <name>".
- opening.line: ONE sentence (when the brief lists what the first sentence must say, all of it goes in this one
  sentence), composed from what the brief says it must convey (e.g. assistant + bank +
  recorded). Use <bank> (or <self>, which already contains the bank name: never both in a way that repeats it). Do not add the right-party question here (it is right_party.ask; the agent says
  opening.line then right_party.ask). verbatim = true only if the brief dictates the exact sentence.
  must_convey from {assistant, bank, recorded, purpose_free} (purpose_free = the purpose is not said).
  The opening must contain no word that is banned before verification.
- banned.before_verification: every word or phrase the brief forbids before identity is verified (as written),
  plus the spoken product names, plus generic disclosure words that would reveal the purpose (debt, payment,
  overdue, late, owe, amount, balance, loan, card, arrears; in the call language, e.g. Turkish borç, ödeme,
  gecikme, tutar, bakiye, kredi, kart) unless the brief allows them. Lowercase, in the call language, as the
  dictionary form (the builder also catches the word with endings: borç -> borcunuz).
  banned.never_offer: offers the brief forbids (discounts, waivers, plans...). banned.never_ask: questions the brief
  forbids (e.g. asking what the customer can afford). banned.always: words never to say at all ([] if none).
- right_party: ask = the brief's right-party question with placeholders (e.g. "Is this <customer>?");
  reask = the question asked again (same text unless the brief says otherwise). confirm_examples /
  non_confirm_examples: the brief's lists (add the generic "<own name>" entry if the own name confirms).
  accept_own_name: whether saying the own name confirms. max_asks: total asks including the first one (one initial ask plus one
  repeat = 2). on_unresolved: the situation when it stays unclear (S_UNCLEAR).
  answers: one short line each for "who" (who is calling; may use <self>), "why" (why are you calling, before
  verification: never the purpose) and "other". bare_no: "third_party" if a bare "No." means someone else answered.
- third_party: disclose is always "nothing_beyond_opening". reach_ask: asks when the customer can be reached
  (uses <customer>, never the purpose). reach_reask: asks again for another time, naming the allowed window in
  plain words. outside_line: says the offered slot is outside what can be arranged. vague_line: asks for an exact
  day and time. time_ask (optional): asks only for the time when a day or a part of the day was given.
  booked_line: thanks + "<date> at <time>". offer_to_pay_line: politely declines to discuss the matter
  with anyone but <customer>. relative_may_verify / relative_may_pay: false unless the brief allows it.
  callback.date_rule: allowed callback days (include_today, today_must_be_business_day, business_days_ahead,
  calendar_days_ahead): "today or the next two business days" = include_today true, business_days_ahead 2.
  callback.windows: time windows (HH:MM, inclusive flags as the brief says, days any|business|non_business).
  after_now: true when the slot must be later than now. reask_limit: how many outside offers get another ask
  before closing (one more ask after an outside offer = 1). vague_asks: free clarifications of a vague time (1).
  situations: callback -> S_CALLBACK, no_callback -> S_NO_CALLBACK. turn_budget: max third-party turns (default 6).
  mode: "callback" when the brief asks a third party when the customer can be reached; "close" when the brief says
  never to ask or never to book a callback: then close_line = the one sentence said to the third party (as the
  brief words it), the call ends right after it with situations.no_callback, and the reach/outside/vague/booked
  lines are not used (give them generic text, never a goodbye).
- bank.currency: keep the brief's own sign ($, £, €) as the symbol. Only when the brief writes amounts with a
  letter code ("USD 348") set the word ("dollars") instead of the code, which TTS reads letter by letter.
- Third-party events that end the call (wrong number, deceased) are intents of facet F5, not of this facet.
