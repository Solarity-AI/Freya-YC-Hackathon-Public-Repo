Facet F2: the identity check.

- questions: in the order the brief asks them, one object each:
  key (short snake_case), field_value (the verify tool's identity selector enum value for this question, or the
  request field name when the API has one field per question), kind (date | digits | year | alnum | text),
  numeric_order (how a date said only in numbers is read: DMY | MDY | YMD, from the brief), wire_format (date:
  strftime-like as the API wants, e.g. "%Y-%m-%d"; digits: "digits"; year: "%Y"; alnum: "upper" when the API or
  the brief keeps a separator in the value (a space or hyphen, e.g. "one space before the last three characters";
  the pattern then contains that separator), else "upper_nospace"; text: "as_is"), length (exact length of a digits/alnum answer, e.g. 4 for "last four digits"; 0 if unknown),
  pattern (regex the wire value must match, e.g. "^[0-9]{4}$"; "" if none), ask (the question, which may start
  with a short lead-in), reask_wrong (after a wrong answer: says it does not match and asks again),
  ask_full (asks for the complete answer after a partial or unreadable one), max_wrong (per-question wrong limit;
  0 = only the total limit applies), two_digit_year (kind year: "ask_full" when a two-digit year must not be guessed
  or sent and the full year is asked, the default; "pivot" only when the brief says a two-digit year is completed).
  For a code whose length varies (e.g. a postcode) length is 0 and the pattern carries the shape.
- max_wrong_total: wrong answers in total that end the check ("N wrong answers in total" = N).
- hints: for each hint value the verify tool can return that the brief gives a rule for: value (hint enum value),
  counts_as_wrong (false when the brief says the retry does not count), say (the line asking for the fix in another form), max (how many times; 1 unless the brief says otherwise).
- decline: explain (the brief's explanation of why the questions are asked), explain_times (1), max_declines
  (refusals on the same question that close the call; closing on the 2nd refusal = 2), purpose_question_counts
  (true when asking what the call is about instead of answering counts as declining).
- fail_line: said when the check fails (what the brief says to tell the customer), never stating the debt. Say each
  thing once: no closing.per_situation line may repeat it. decline.explain is a statement and never ends with a
  question (the identity question follows it).
- on_failed: S_ID_FAILED. on_declined: S_ID_DECLINED. turn_budget: 12 unless the brief says otherwise.
- verified_prefix: a short acknowledgement said right after the last question passes ("Thank you.").
- Every line of this facet is spoken before verification: no banned word (no purpose, no product, no amount).
