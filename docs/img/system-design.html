How the Builder Works

One command: python3 builder/build.py <case_folder> <mock_url> · the bank's documents go in, a Turkish-speaking Freya phone agent comes out

3 · The model listens, code decides

Freya model

  • Copies the customer's words, and an English rendering
  • Reads Turkish answers as typed values: date, digits, amount
  • Picks the kind of reply: yes, no, answer, question
  • Picks the topic: hardship, dispute, paid, human
  • Speaks only lines the code chose

Code brain

  • Checks every model-read value; resolves "yarın", "cuma" from the call date
  • Business days, Turkish holidays, deadlines
  • Amounts in cents, minimum payment, the offer ladder
  • Identity answers, wrong-answer counts, hints
  • Which product is next, when to read back
  • Every bank call and its exact values
  • Outcome, reason and notes for the close
  • Speaks "23 Ekim Cuma", "1.250,00 TL"

4 · Safety rails

  • Nothing about the debt is said before identity is verified; lines before that are fixed text
  • No bank write runs twice: each write node is guarded and entered once
  • A failed promise is retried once; "recorded" is said only after success
  • close_call is always the last call; no reason on promise or paid
  • Memo changes apply by the call's own date; Turkish national holidays built in
  • Forbidden words caught with Turkish endings (borç → borcunuz)
  • Long calls wrap up before the platform's 131 KB limit
  • Nothing from Brief A/B is in the builder; a leak check runs on every fix
